# User Stories

## Guest Users

- can view book-list, book-detail
- can view author-list, author-detail
- can view available book-copies
- can register an account with email
- can log-in

## Logged-in Users

- can borrow a book-copy if it is available
- can only borrow max 3 copies at the same time
- can return a copy
- can log-out

## group Librarian

- Librarians have more permissions
- can add, update books, authors, book-copies
- can mark a book-copy as returned
- can extend a book-copy's due-date, max 4 weeks ahead

## Admin Users

- Admins have all permissions
- Admins can delete books, authors, book-copies
